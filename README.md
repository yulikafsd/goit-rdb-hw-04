# goit-rdb-hw-04
DML and DDL commands. SQL expressions

У даному репозиторії представлено виконання практичного завдання з проєктування структури реляційної бази даних (DDL), заповнення даними (DML), а також написання аналітичних багатотабличних SQL-запитів із використанням `JOIN`, фільтрації, агрегації та групування.

---

#### 4.2. Зміна INNER JOIN на LEFT JOIN та аналіз результатів
Запит із `LEFT JOIN` також повертає **518** рядків.
![Результат 4.2](screenshots/p4_2_count_left.png)

> **Пояснення:**  
> Кількість рядків не змінюється, тому що базовою таблицею у `FROM` виступає `order_details`. База даних має повну цілісність даних (Referential Integrity): для кожного запису в `order_details` обов'язково існують відповідні записи у батьківських таблицях, а в зовнішніх ключах відсутні значення `NULL`. Відповідно, `LEFT JOIN` не додає жодного рядка з незбіжними даними. Зареєстровані клієнти без замовлень у вибірку не потрапляють, оскільки зв'язок будується від факту замовлення.
